# Contributing

Read [Development](docs/development.md) and [Architecture](docs/architecture.md)
before changing code. Discuss substantial changes in an issue first, keep PRs
focused, and update the relevant guide when behaviour changes. Run focused
checks locally; the PR workflow runs the complete configured checks.

Submit only work you have the right to contribute under GPL-3.0-only. Your
original contributions use the project's licence; you retain your copyright.
Identify copied or adapted code, assets and their sources and preserve all
required notices. Do not contribute proprietary code, brush packs, models,
fonts, logos, credentials or private diagnostic bundles without the necessary
rights. Tool-generated material needs the same review.

When dependencies change, regenerate the third-party notices and review the
licence diff. Include source, version, licence and attribution for new assets.
Do not claim support for a platform without recording its build and runtime
validation. Report bugs with the version, OS, GPU and minimal reproduction;
review diagnostic bundles for private artwork and paths before sharing them.

Be respectful, constructive and welcoming. Disagreement should focus on the
work, and harassment is not acceptable.
