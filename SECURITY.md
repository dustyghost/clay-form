# Security

Clay Form is currently a prototype. Security fixes target the latest source
and release; there is no long-term support commitment for older versions.

Do not post exploit details, credentials, private artwork or diagnostic bundles
in public issues. Use GitHub's private vulnerability reporting on the
[Security page](https://github.com/dustyghost/clay-form/security) when enabled.
Before the repository becomes public, the maintainer must enable private
vulnerability reporting and verify that a report can be submitted.

Reports should identify the version/commit, affected platform, impact and a
minimal reproduction that contains no confidential material. There is no
promised response deadline yet.

Treat imported projects, meshes and images as untrusted input. Do not run Clay
Form as administrator/root. Optional GIMP and Blender integration executes
locally installed tools; keep those applications updated as well.
