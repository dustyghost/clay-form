# Guide screenshots

The guides use real egui/OpenGL captures of practice scenes. Panel-only images render the app's actual controls at a readable size; full-window images show navigation or a spatial result. No screenshot is painted over or generated by AI.

## Regenerate

On Linux with Rust and Mesa/EGL installed, run from the repository root:

```sh
bash scripts/update-doc-screenshots.sh
```

The script uses software rendering, defaults to two Mesa threads, and saves extra frames in a temporary directory printed at completion. Selected PNGs are copied only after all capture tests pass. It also exports the two sample reference images into `docs/examples/`.

See [Development](../development.md#update-guide-screenshots) for prerequisites and [documentation style](../documentation-style.md#make-every-screenshot-answer-a-question) for composition and review guidance.
