# UV and image workflow implementation

The unwrap follows the two area-weighted Cauchy–Riemann residuals in [Lévy et al., Least Squares Conformal Maps, SIGGRAPH 2002](https://brunolevy.github.io/papers/LSCM_SIGGRAPH_2002.pdf). Face corners are joined across uncut manifold edges, so a seam creates distinct UV unknowns without changing geometric vertices. Two separated boundary nodes fix the similarity freedom. A matrix-free, Jacobi-preconditioned conjugate-gradient solve minimizes the normal equations; nonconvergence and nonpositive output triangle areas fail before commit. Cancellation is checked during chart construction and iteration.

Chart segmentation and packing are deliberately simpler than the paper's methods: automatic cuts use six dominant face-normal directions, manual mode follows marked seams, and a deterministic shelf packer uses a uniform scale with explicit padding. Closed/nonmanifold charts and folded results need more seams. There is no claim that every input produces an injective parameterization; the editor separately checks overlap and reports its bounded-work limit. The generated cylinder, cube and sphere fixtures cover the intended initial workflows.

`Mesh::uv` stores triangle-corner coordinates and the topology they belong to. A topology mismatch disables rendering and painting through the old mapping. New saves use version 3 to prevent older applications silently discarding UVs or images. Images have stable IDs, copy-on-write RGBA16 pixels, explicit channel interpretation and optional external-exchange metadata. Four million unique pixels bound the scene's GPU image buffer; history conservatively counts image storage. Image data remains embedded in native projects. Diagnostic exports remove external exchange paths.

The GPU receives per-corner UVs independently of smoothing fans and per-model texture descriptors into a deduplicated pixel buffer. Bilinear filtering operates on premultiplied linear samples. Paint rasterizes UV triangles, interpolates masks and surface positions, and evaluates the brush in 3D. Projected triangle bins accelerate exact frontmost-surface checks. A stroke uses the existing transactional paint history and propagates images to shared IDs. Four-pixel gutter dilation never crosses occupied UV texels.

GIMP integration uses an executable plus one literal file argument, without a shell. A fingerprint of the exported pixels/dimensions detects concurrent local changes. Decode, profile conversion and validation finish before replacing the current image. The pinned `moxcms` library, already present transitively through `image`, performs RGB ICC conversion. Linear data images bypass it. The manual GIMP fixture is separate from routine CI.
